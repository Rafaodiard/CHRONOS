Castle Dungeon Tileset Pack

A set of 441 hand-drawn tiles for creating dungeons in two styles: classic and icy.
Suitable for 2D games.

Format
- Tile size: 32x32 px
- Format: PNG
- Includes: one general tilesheet and four categorized tilesheets

Contents
- Walls and floors
- Doors and grates
- Carpets and banners
- Statues and chests
- Decor
- Windows and bookshelves

Author: Alxn3
